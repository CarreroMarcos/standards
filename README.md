# Standards

A personal library of engineering standards for AI coding agents — researched, versioned, and written in the language agents actually follow.

The goal is simple: make AI write senior-level code instead of slop. Every rule earned its place: observed in real systems, stated as a positive recipe with its why, kept only if it changes what the agent produces.

- `AGENTS.md` — the portable starter. Drop it into any repo as-is.
- `AGENTS-PUBLIC.md` — the same starter, zero dependencies on this library. Share freely.
- `standards/` — the full library, one topic per file.
